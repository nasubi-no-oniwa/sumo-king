# 相撲キング

横綱 紫煙山、一服。マイクにひと息「フーーッ」と吹くと、横綱が煙を吐いてやせていく。吐けた秒数で番付が決まる。

遊ぶ：https://nasubi-no-oniwa.github.io/sumo-king/

- `index.html` … ゲーム本体（1つのファイル）
- `database.rules.sumo.json` … ランキングのルール。GitHub に上げると自動で ft-green の `sumo` に反映（ほかのゲームのルールはそのまま）
- `test/rules-test.mjs` … ルールの試験（GitHub の上で試し用のデータベースを立てて試す）

## しくみ
- 息の判定：マイクの音の強さが「線」より上のあいだを数える。0.5秒より長く線の下に落ちたら終わり
- 線の高さ：はじめに一度だけ「フッ」と吹いてもらった強さと、まわりの静けさから決める
- 声（とがった音の山がいくつも出る）が1秒続いたら反則。8秒ずっと同じ強さの音（扇風機など）も反則
- 吹きはじめた瞬間にサーバーの時刻を `sumo/runs/人` に書く。記録はその時刻から実際に時間がたっていないと載らない
- 番付：序ノ口 → 序二段（5秒）→ 三段目（10秒）→ 幕下（15秒）→ 十両（20秒）→ 前頭（25秒）→ 小結（30秒）→ 関脇（40秒）→ 大関（50秒）→ 横綱（1分）→ 相撲キング（3分）
- 隠し結末：MVで横綱がたばこをくわえる前に、右上のスキップを横にずらすと「禁煙する」が出る。禁煙した人の数は `sumo/quit` に1人1つ
- 消したい記録は、Firebase の `sumo/hidden/人のID` に `true` を入れるとランキングに出なくなる
